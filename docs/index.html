What is this?

This project simulates a two-link robotic arm. The Python implementation contains the actual simulation, controller, kinematics and metrics. This page is a simple visual interface for exploring some of the results.

METHOD

How it works

  1. Model the two-link robot.
  2. Calculate its kinematics and dynamics.
  3. Apply a controller to move the joints.
  4. Measure the resulting behaviour.
  5. Compare controller configurations.
