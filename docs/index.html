What is this?

This project simulates a two-link robotic arm. The Python implementation contains the actual simulation, controller, kinematics and metrics. This page is a simple visual interface for exploring some of the results.

COMPARISON

Step target vs trajectory vs feedforward

The same move at three gain settings. A step target asks for the whole move at once, so torque spikes with Kp. A planned trajectory removes the spike; feedforward adds the torque the motion needs, so the arm follows the plan almost exactly.

METHOD

How it works

  1. Model the two-link robot.
  2. Calculate its kinematics and dynamics.
  3. Plan a smooth trajectory to the target.
  4. Apply a controller to follow the trajectory.
  5. Measure the resulting behaviour.
  6. Compare controller configurations.

OPTIMIZATION

Pareto Frontier

A controller is Pareto-optimal when no other controller is at least as good on every metric (settling time, steady-state error, overshoot, peak torque, tracking) and better on one. Each point is one such controller for the selected control law.
